⚙️ Réglages & Mobile
Android : ouvrez ce fichier dans Chrome → menu ⋮ → Ajouter à l'écran d'accueil.

iPhone : Safari → bouton Partager → Sur l'écran d'accueil.

Important : les données restent dans le navigateur du téléphone. Exportez régulièrement votre sauvegarde JSON vers Drive.

Rappels : un fichier local ne peut pas envoyer de notifications seul. Utilisez les boutons 🔔 — ils créent l'événement dans votre agenda (Google/Apple) qui s'occupe de vous notifier.
